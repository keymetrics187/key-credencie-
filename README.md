# Controle de Credenciamento

App em Streamlit para leitura de QR Code e controle de presença com integração ao Google Sheets.

## Funcionalidades
- Leitura de QR Code com câmera traseira (mobile)
- Marcação automática de check-in na planilha
- Estatísticas de participantes
- Interface simples para uso em eventos

## Como usar
1. Faça upload do app para o [Streamlit Cloud](https://streamlit.io/cloud)
2. Configure as credenciais do Google Sheets em `Secrets`
3. Compartilhe o link com o time de credenciamento
